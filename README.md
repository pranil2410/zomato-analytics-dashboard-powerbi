# Zomato Analytics Dashboard | Power BI

## Project Overview

This Power BI project analyzes restaurant data from Zomato and provides insights into restaurant performance, customer preferences, ratings, cuisines, locations, and online ordering trends.

---

## Dashboard Pages

### 1. Overview

- Total Restaurants
- Average Rating
- Total Votes
- Average Cost
- Top Restaurant Locations
- City Filter

### 2. Performance Analysis

- Restaurant Rating Distribution
- Restaurant Distribution Map
- Restaurant Types Analysis
- Cost Segment Analysis
- Table Booking Analysis

### 3. Business Insights

- Online Ordering Share
- Top Cities by Restaurant Count
- Popular Cuisines
- Cost vs Rating Analysis
- Interactive City Filter

---

## Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization

---

## Key Insights

- Quick Bites dominate the restaurant market.
- Budget and Mid-Range restaurants represent the largest segment.
- Online ordering is adopted by a majority of restaurants.
- North Indian cuisine is among the most popular categories.
- Ratings and cost show interesting customer preference trends.
